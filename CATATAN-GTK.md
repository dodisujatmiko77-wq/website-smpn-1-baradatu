# Modul GTK (Guru & Tenaga Kependidikan)
1. Supabase → SQL Editor → jalankan `supabase/gtk.sql`.
2. Admin → menu GTK → Guru / Tenaga Kependidikan → Tambah. Isi data selengkapnya.
3. Centang "Tampilkan ..." hanya untuk data yang boleh tampil publik (mis. NIP tidak dicentang = tidak tampil dan tidak dikirim ke pengunjung).
4. Ubah Status ke "Terbit" agar muncul di /gtk/guru dan /gtk/tendik.
Catatan: NIK sengaja tidak disediakan. Foto saat ini berupa URL (seperti modul lain).
