# ADMIN PANEL V1 — WEBSITE UPT SMPN 1 BARADATU

Baseline publik tetap berasal dari `smpn1-baradatu-final-v1-locked.zip`.

Yang ditambahkan:
- `/admin/login`
- `/admin` Dashboard
- `/admin/homepage` kontrol visibilitas section homepage
- `/admin/profil` identitas sekolah
- `/admin/konten/news`
- `/admin/konten/announcements`
- `/admin/konten/agenda`
- `/admin/konten/achievements`
- `/admin/konten/gallery`
- `/admin/konten/services`
- `/admin/audit`

Prototype menggunakan localStorage agar bisa diuji tanpa kredensial database. `supabase/schema.sql` adalah rancangan database produksi.
